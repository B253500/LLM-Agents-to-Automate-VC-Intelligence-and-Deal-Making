# Web Scraping Workflow

This directory contains the web scraping and data collection workflow for VC reports and market data.

## Files

### download_reports.py
Main web scraping script for downloading VC reports and market data.

### scripts/
Directory containing specialized web scraping scripts for different data sources.

### results/
Directory containing scraped data and analysis results.

## Usage

1. Run `python download_reports.py` to start web scraping
2. Check `results/` directory for downloaded data
3. Use specialized scripts in `scripts/` for specific data sources

## Data Sources

- VC reports and market analysis
- Industry data and trends
- Company information and metrics
